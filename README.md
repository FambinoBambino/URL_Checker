# URL_Checker
This addon allows users to check URLs / sites using VirusTotal. This ranges from being able to right-click on a link or page and checking for VT results to storing links within a folder, so that you can easily re-scan common links as often as you need and with ease of location. A VirusTotal API key is required, but can acquired for free, visit https://docs.virustotal.com/docs/please-give-me-an-api-key for more information.
