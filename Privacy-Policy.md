# Privacy Policy — URL Checker

**Last updated: August 2026**

URL Checker is an open-source Firefox extension that allows users to submit URLs to VirusTotal for security analysis.

## Data Sent to VirusTotal

When you choose to scan a URL, URL Checker sends the URL you selected to VirusTotal through the VirusTotal API. The request is made using the VirusTotal API key provided by you.

The developer of URL Checker does not collect, store, or receive the URLs you submit through a separate server, analytics service, or other data collection system.

VirusTotal may retain, analyze, and share submitted information according to its own terms and policies. Please review VirusTotal's applicable Terms of Service and Privacy Policy before using the extension.

- [VirusTotal Terms of Service](https://cloud.google.com/terms)
- [VirusTotal Privacy Policy](https://cloud.google.com/terms/secops/privacy-notice)
- [How VirusTotal Works](https://docs.virustotal.com/docs/how-it-works)

**Please do not submit URLs containing personal, confidential, or commercially sensitive information unless you understand the implications of submitting that information to VirusTotal.**

## Locally Stored Data

URL Checker stores certain information locally using Firefox's extension storage. This may include:

- Your VirusTotal API key
- URLs that you save to folders
- Folder organization
- VirusTotal scan results
- Extension preferences (such as themes or context menu style)

This locally stored information is not transmitted to the developer.

## API Key

URL Checker requires you to provide your own VirusTotal API key. The key is stored locally using Firefox's extension storage and is sent to VirusTotal when making API requests.

The developer does not receive or have access to your API key.

## Analytics and Tracking

URL Checker does not use advertising, analytics, tracking, telemetry, or user profiling.

The extension does not collect your browsing history or transmit browsing activity to the developer.

URLs are transmitted to VirusTotal when you initiate a scan or use an extension feature that requires a URL to be submitted for analysis.

## Changes to This Policy

This privacy policy may be updated if the extension's data handling practices change.

The current version of this policy will be available in the extension's public GitHub repository and in the extension's listing on Mozilla Add-ons.

## Contact

For questions about this privacy policy or the extension's data handling practices, please use the contact information provided on the extension's project page.
